# Stock Desk

Inventory planning, purchase orders and receiving for **Smash Beauty Supply** and
**Venerate Beauty Supply**. Both Shopify stores sync automatically every hour; the page
works the same as the original Stock Desk (Dashboard, Inventory, Replenishment,
Purchase orders, Markdowns, Dead stock, Data fixes, Settings).

## How it fits together

| Part | What it does |
|---|---|
| `src/server.js` | Web app: sign-in, serves the Stock Desk page, document API, Shopify proxy |
| `src/sync.js` + `src/cron.js` | Reads variants, stock, costs and 24 months of sales from each store (Render cron, hourly) |
| `src/shopify.js` | Shopify Admin API via the client credentials grant (Dev Dashboard apps) |
| `src/alerts.js` | Emails newly negative stock after each sync (optional, via Resend) |
| `public/index.html` | The Stock Desk page, unchanged except for server sync and store routing |
| `public/shim.js` | Stands in for the claude.ai artifact runtime (`db`, Shopify, downloads) |
| `render.yaml` | Render Blueprint: web service, cron job, Postgres |

## Safety

- **Shopify stock changes are off** until `ALLOW_SHOPIFY_WRITES=true`. Until then, receiving
  records units on the PO only and shows a message instead of changing Shopify.
- The only Shopify write allowed from the page is the stock adjustment mutation
  (`inventoryAdjustQuantities` with `changeFromQuantity` and an idempotency key).
- Secrets live only in Render environment variables.

## Settings (Render environment)

| Setting | Notes |
|---|---|
| `SMASH_SHOP`, `VENERATE_SHOP` | The `xxxx` part of `xxxx.myshopify.com` |
| `SMASH_CLIENT_ID` / `SMASH_CLIENT_SECRET` | From the "Smash Stock Desk" app in the Shopify Dev Dashboard |
| `VENERATE_CLIENT_ID` / `VENERATE_CLIENT_SECRET` | From the "Venerate Stock Desk" app |
| `APP_USERS` | Logins, `name:password,name2:password2` |
| `SESSION_SECRET`, `API_KEY` | Generated by Render |
| `ALLOW_SHOPIFY_WRITES` | `false` until testing is done |
| `ALERT_EMAIL`, `ALERT_FROM`, `RESEND_API_KEY`, `APP_URL` | Optional negative-stock emails |

Shopify app access scopes: `read_products, write_products, read_inventory, write_inventory, read_locations, read_orders, read_reports`.
The apps must be in the same Shopify organization as the stores (client credentials grant).

## Local checks

`node test/mock-server.js 4321` serves the page against an in-memory mock (no Postgres or
Shopify needed).

## Importing data from the old Stock Desk page

`DATABASE_URL=... node scripts/import.js <export-folder>` — store snapshots are skipped and
rebuilt by the first sync.
